# HotPlainText

[English](README.md) | [日本語](README.ja.md) | [简体中文](README.zh-Hans.md) | **한국어** | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md)

단축키(⌃⌘C)로 서식 없이 복사합니다. macOS 메뉴 막대 앱.

웹 등에서 복사한 글의 서식(색, 굵은 글씨, 링크 등)을 없애고 글자만 남기는 작은 도구입니다.

## 만들게 된 이유

### 불편했던 점

Windows에서 Mac으로 옮긴 뒤 가장 불편했던 것은 ‘서식 포함 복사’였습니다.
웹 페이지의 글을 복사해 붙여넣으면 색, 크기, 링크, 굵은 글씨까지 함께 따라옵니다.

Windows에서는 메모장에 한 번 붙여넣고 다시 복사하면 깨끗한 글자만 얻을 수 있었습니다. 메모장은 서식을 담을 수 없기 때문입니다.
게다가 아무 설정 없이도 처음부터 그렇게 쓸 수 있습니다.

하지만 Mac의 ‘메모’나 ‘텍스트 편집기’는 서식을 그대로 남기기 때문에 같은 방법을 쓸 수 없습니다.
텍스트 편집기를 일반 텍스트로 바꾸거나 키보드 단축키를 다시 지정하면 비슷하게 할 수는 있습니다. 하지만 어느 쪽이든 직접 설정을 바꿔야 합니다.
Windows에서는 아무것도 하지 않아도 되던 일이, Mac에서는 설정을 해야만 됩니다.

### 다른 사람들은 어떻게 하는지

찾아보니 Mac에서는 주로 다음과 같은 방법이 있습니다.

- **⌥⇧⌘V(붙여넣고 스타일 일치)**: macOS 기본 기능입니다. 다만 키를 누르기 불편하고, 작동하지 않는 앱도 있습니다.
- **⌘V를 ‘붙여넣고 스타일 일치’로 바꾸기**: 시스템 설정에서 지정할 수 있지만, 메뉴에 그 항목이 있는 앱에서만 작동합니다.
- **복사하면 자동으로 서식을 없애는 상주 앱**: Pure Paste, Rinse, PlainText – Clipboard Cleaner 등.
- **클립보드 기록 앱의 기능**: Raycast, Alfred, Maccy 등에 있는 ‘서식 없이 붙여넣기’.
- **복사할 때 없애는 도구**: CleanBoard(⌘C를 두 번 누르기), Plaintext!(⌘C 다음에 ⌃⌫).

몇 가지 앱을 살펴봤지만 저에게는 와닿지 않았습니다.
대부분은 ‘붙여넣을 때 없애기’나 ‘복사한 것을 모두 자동으로 없애기’ 중 하나였습니다.
서식 없는 복사를 한 번에 할 수 있고, 서식 포함 복사도 한 번에 할 수 있는 것.
그런 것이 없어서 직접 만들었습니다.

### 만들면서 정한 것

1. **처음에는 웹 버전**: 서식을 담을 수 없는 입력란에 붙여넣고 다시 복사합니다(Windows 메모장과 같은 생각). `index.html`에 남아 있습니다.
2. **Mac 앱으로 만들었다**: 같은 일을 하는 윈도우를 만들었습니다.
3. **어느 앱에서나 작동하는 단축키**: 글자를 선택하고 누르기만 하면 서식 없이 복사합니다. 키는 **⌃⌘C**로 정했습니다. 평소의 ⌘C에 ⌃만 더하면 되니 외우기 쉽고, macOS 기본이나 주요 앱의 단축키와 겹치지 않습니다.
   - 후보에서 뺀 것: ⌘X(오려두기), ⌘B(볼드체), ⌃C(터미널에서 명령 중지), ⌥⌘C(Finder에서 경로 이름 복사).
4. **⌘C와 ⌃⌘C 바꾸기**: 평소의 ⌘C를 서식 없는 복사로 쓰고 싶을 때를 위해, 메뉴의 체크로 바꿀 수 있게 했습니다. 지금 어느 키가 무엇을 하는지는 메뉴 맨 위의 패널에서 언제든지 볼 수 있습니다.
5. **7개 언어 지원**: 영어, 일본어, 중국어(간체), 한국어, 독일어, 프랑스어, 스페인어.

## Mac 앱(HotPlainText)

- 어느 앱에서나 글자를 선택하고 **⌃⌘C**를 누르면 서식 없이 복사합니다(손쉬운 사용 권한이 필요합니다)
- 윈도우에 붙여넣으면 서식이 사라집니다. ‘붙여넣기’로 붙여넣고, ‘복사하기’로 서식 없이 복사합니다(선택한 부분이 있으면 그 부분, 없으면 전체)
- 메뉴 막대에서 ‘⌘C와 ⌃⌘C 바꾸기’, ‘로그인 시 실행’, ‘언어’를 바꿀 수 있습니다

### 설치

자신의 Mac에서 빌드해서 설치합니다. 그 Mac에서 만든 앱이므로 ‘개발자를 확인할 수 없습니다’라는 경고가 나오지 않습니다.

필요한 것: macOS 14 이상, Xcode 명령어 도구(없다면 `xcode-select --install`).

```bash
git clone https://github.com/xzelvox/HotPlainText.git
cd HotPlainText/HotPlainText && ./install.sh
```

`install.sh`는 앱을 빌드하고, 이전 HotPlainText가 있으면 종료한 다음 지우고, 새 앱을 설치해서 엽니다. 임시 서명일 때는 이전 손쉬운 사용 권한도 지우므로, 앱이 열리면 안내대로 다시 권한을 줍니다.

빌드할 때 임시 서명을 사용한다는 일본어 안내가 나옵니다. 그대로 두면 됩니다.

앱을 처음 열면 ⌃⌘C에 필요한 손쉬운 사용 권한을 주는 방법이 나옵니다. 안내대로 권한을 주면 앱이 자동으로 다시 열립니다. 메뉴 맨 위의 패널에 초록색 점과 ‘손쉬운 사용: 허용됨’이 나오면 사용할 수 있습니다.

새 버전으로 바꿀 때는 `git pull`을 한 다음 `./install.sh`를 다시 실행합니다.

아이콘은 `make_icon.swift`로 그렸습니다.

앱은 영어, 일본어, 중국어(간체), 한국어, 독일어, 프랑스어, 스페인어를 지원하며, Mac의 언어 설정에 맞춰 바뀝니다(지원하지 않는 언어라면 영어). 메뉴의 ‘언어’에서 고를 수도 있습니다.
문구는 `*.lproj/Localizable.strings`에 있습니다(영어가 기본 언어이고, 키가 그대로 표시됩니다). 모든 언어의 번역 목록은 `HotPlainText/TRANSLATIONS.md`에 있습니다.

## アクセシビリティの許可の手順(`accessibility.guide`)

### 英語

```
1. Click “Open System Settings”.
2. If HotPlainText is already in the list, select it and remove it with “−”.
   (An old permission may not work after the app is rebuilt.)
3. Click “+” and add HotPlainText from the Applications folder.
   (You can also drag it from the Finder window that opens.)
4. Turn on the HotPlainText you added.
5. When the permission is on, HotPlainText reopens by itself.

You’re done when the menu shows “Accessibility: Allowed”.
```

### 日本語

```
1. 「システム設定を開く」を押します。
2. 一覧に HotPlainText があれば、選んで「−」で消します。
   (アプリを作り直した後は、以前の許可が効かないことがあります)
3. 「+」を押し、アプリケーションフォルダの HotPlainText を追加します。
   (一緒に開く Finder の窓からドラッグしても追加できます)
4. 追加した HotPlainText をオンにします。
5. 許可がオンになると、HotPlainText が自動で開き直します。

メニューに「アクセシビリティ: 許可あり」と出れば完了です。
```

### 中国語(簡体字)

```
1. 点按“打开系统设置”。
2. 如果列表中已有 HotPlainText,请选中它并点按“−”将其移除。
   (重新构建应用后,旧的权限可能不再有效)
3. 点按“+”,从“应用程序”文件夹中添加 HotPlainText。
   (也可以从同时打开的访达窗口中拖入)
4. 打开刚添加的 HotPlainText 的开关。
5. 权限打开后,HotPlainText 会自动重新打开。

菜单中显示“辅助功能:已允许”即表示完成。
```

### 韓国語

```
1. ‘시스템 설정 열기’를 클릭합니다.
2. 목록에 HotPlainText가 있으면 선택한 다음 ‘−’로 제거합니다.
   (앱을 다시 빌드한 후에는 이전 권한이 작동하지 않을 수 있습니다)
3. ‘+’를 클릭하고 응용 프로그램 폴더에서 HotPlainText를 추가합니다.
   (함께 열리는 Finder 윈도우에서 끌어다 놓아도 됩니다)
4. 추가한 HotPlainText를 켭니다.
5. 권한이 켜지면 HotPlainText가 자동으로 다시 열립니다.

메뉴에 ‘손쉬운 사용: 허용됨’이 표시되면 완료입니다.
```

### ドイツ語

```
1. Klicke auf „Systemeinstellungen öffnen“.
2. Wenn HotPlainText bereits in der Liste ist, wähle es aus und entferne es mit „−“.
   (Nach einem Neubau der App funktioniert eine alte Berechtigung eventuell nicht mehr.)
3. Klicke auf „+“ und füge HotPlainText aus dem Ordner „Programme“ hinzu.
   (Du kannst es auch aus dem geöffneten Finder-Fenster hineinziehen.)
4. Schalte das hinzugefügte HotPlainText ein.
5. Sobald die Berechtigung aktiv ist, öffnet sich HotPlainText von selbst neu.

Fertig, wenn im Menü „Bedienungshilfen: Erlaubt“ steht.
```

### フランス語

```
1. Cliquez sur « Ouvrir Réglages Système ».
2. Si HotPlainText figure déjà dans la liste, sélectionnez-le et supprimez-le avec « − ».
   (Après une recompilation de l’app, une ancienne autorisation peut ne plus fonctionner.)
3. Cliquez sur « + » et ajoutez HotPlainText depuis le dossier Applications.
   (Vous pouvez aussi le faire glisser depuis la fenêtre du Finder qui s’ouvre.)
4. Activez le HotPlainText que vous venez d’ajouter.
5. Dès que l’autorisation est activée, HotPlainText se rouvre tout seul.

C’est terminé lorsque le menu affiche « Accessibilité : autorisée ».
```

### スペイン語

```
1. Haz clic en «Abrir Ajustes del Sistema».
2. Si HotPlainText ya está en la lista, selecciónalo y elimínalo con «−».
   (Tras recompilar la app, un permiso antiguo puede dejar de funcionar.)
3. Haz clic en «+» y añade HotPlainText desde la carpeta Aplicaciones.
   (También puedes arrastrarlo desde la ventana del Finder que se abre.)
4. Activa el HotPlainText que has añadido.
5. Cuando el permiso esté activado, HotPlainText se volverá a abrir solo.

Habrás terminado cuando el menú muestre «Accesibilidad: permitida».
```

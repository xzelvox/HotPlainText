# HotPlainText

[English](README.md) | [日本語](README.ja.md) | **简体中文** | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md)

用快捷键(⌃⌘C)以纯文本拷贝。macOS 菜单栏应用。

一个小工具:去掉从网页等处拷贝的文字所带的格式(颜色、粗体、链接等),只留下文字。

## 来由

### 遇到的麻烦

从 Windows 换到 Mac 后,最让我头疼的是“带格式的拷贝”。
从网页拷贝一段文字再粘贴,颜色、字号、链接和粗体都会一起带过来。

在 Windows 上,只要先粘贴到记事本再重新拷贝,就能得到干净的文字,因为记事本保存不了格式。
而且不用做任何设置,一开始就能这么用。

可是 Mac 的“备忘录”和“文本编辑”会原样保留格式,同样的办法行不通。
把“文本编辑”切换成纯文本,或者重新分配键盘快捷键,可以做到差不多的效果,但都得自己去改设置。
在 Windows 上什么都不用做就能办到的事,在 Mac 上却要先设置。

### 别人是怎么做的

查了一下,在 Mac 上主要有这些办法:

- **⌥⇧⌘V(粘贴并匹配样式)**:macOS 自带的功能。不过按键不好按,有些应用也不支持。
- **把 ⌘V 换成“粘贴并匹配样式”**:可以在系统设置里分配,但只在菜单里有这一项的应用中有效。
- **拷贝后自动去掉格式的常驻应用**:Pure Paste、Rinse、PlainText – Clipboard Cleaner 等。
- **剪贴板历史应用的功能**:Raycast、Alfred、Maccy 等都有“以纯文本粘贴”。
- **在拷贝时去掉格式的工具**:CleanBoard(按两次 ⌘C)、Plaintext!(⌘C 之后按 ⌃⌫)。

我试了几个应用,但都不太合我的心意。
它们大多不是“粘贴时去掉格式”,就是“把拷贝的东西全部自动去掉格式”。
我想要的是:纯文本拷贝一下就能完成,带格式的拷贝也一下就能完成。
找不到这样的东西,所以就自己做了。

### 制作过程中做的决定

1. **最初是网页版**:粘贴到保存不了格式的输入框里,再重新拷贝(和 Windows 记事本的思路一样)。保留在 `index.html` 中。
2. **做成了 Mac 应用**:做了一个功能相同的窗口。
3. **在任何应用中都有效的快捷键**:选中文字按一下,就以纯文本拷贝。按键选了 **⌃⌘C**。只是在平常的 ⌘C 上加一个 ⌃,好记,而且不会和 macOS 或主要应用的快捷键冲突。
   - 没有选用的候选:⌘X(剪切)、⌘B(粗体)、⌃C(在终端中停止命令)、⌥⌘C(在访达中拷贝路径名)。
4. **交换 ⌘C 和 ⌃⌘C**:想让平常的 ⌘C 变成纯文本拷贝时,可以用菜单里的勾选来交换。菜单顶部的面板随时显示两个按键各自的作用。
5. **支持 7 种语言**:英语、日语、中文(简体)、韩语、德语、法语、西班牙语。

## Mac 应用(HotPlainText)

- 在任何应用中选中文字并按 **⌃⌘C**,即以纯文本拷贝(需要辅助功能权限)
- 粘贴到窗口中,格式就会消失。用“粘贴”粘贴,用“拷贝”以纯文本拷贝(有选中内容时拷贝选中部分,否则拷贝全文)
- 可以在菜单栏中切换“交换 ⌘C 和 ⌃⌘C”“登录时启动”“语言”

### 安装

在自己的 Mac 上构建并安装。因为应用是在这台 Mac 上构建的,不会出现“无法验证开发者”的警告。

需要:macOS 14 或更高版本,以及 Xcode 命令行工具(如果没有,运行 `xcode-select --install`)。

```bash
git clone https://github.com/xzelvox/HotPlainText.git
cd HotPlainText/HotPlainText && ./install.sh
```

`install.sh` 会构建应用,如果有旧的 HotPlainText,会先退出并删除它,然后安装并打开新的应用。使用临时签名时,还会清除旧的辅助功能权限,所以打开后请按照提示重新授予。

构建时会显示一条日语提示,说明将使用临时签名。这没有问题,可以忽略。

第一次打开应用时,会显示如何授予 ⌃⌘C 所需的辅助功能权限。按照步骤授予权限后,应用会自动重新打开。菜单顶部的面板显示绿点和“辅助功能:已允许”时,就可以使用了。

要更新到新版本,请先运行 `git pull`,然后再运行一次 `./install.sh`。

图标由 `make_icon.swift` 绘制。

应用支持英语、日语、中文(简体)、韩语、德语、法语、西班牙语,会跟随 Mac 的语言设置切换(不支持的语言显示为英语)。也可以在菜单的“语言”中选择。
文字位于 `*.lproj/Localizable.strings` 中(英语是基础语言,键会原样显示)。所有语言的译文一览见 `HotPlainText/TRANSLATIONS.md`。

## 网页版

在浏览器中打开 `index.html`,粘贴后按“すべてコピー”(全部拷贝)。网页版只有日语。

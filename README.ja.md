# HotPlainText

[English](README.md) | **日本語** | [简体中文](README.zh-Hans.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md)

Copy as plain text with a hotkey (⌃⌘C). macOS menu bar app.

Web などからコピーした文字の書式(色・太字・リンクなど)を消して、文字だけにする道具。

## 経緯

### 困っていたこと

Windows から Mac に移って、いちばん困ったのが「書式付きのコピー」だった。
Web ページの文をコピーして貼ると、色や大きさ、リンク、太字まで一緒に付いてくる。

Windows では、いったんメモ帳に貼ってコピーし直せば、まっさらな文字にできた。メモ帳は書式を持てないからだ。
しかも、何も設定しなくても、最初からそう使える。

ところが Mac の「メモ」や「テキストエディット」は書式をそのまま残すので、同じ手が使えない。
テキストエディットを「標準テキスト」に切り替えたり、キーボードのショートカットを割り当て直したりすれば近いことはできる。けれど、どれも自分で設定を変えないといけない。
Windows では何もしなくてもできたことが、Mac では設定をしないとできない。

### ほかの人はどうしているか

調べると、Mac では主に次のやり方がある。

- **⌥⇧⌘V(ペーストしてスタイルを合わせる)**: Mac の標準機能。ただ、キーが押しにくく、効かないアプリもある。
- **⌘V を「スタイルを合わせる」に置き換える**: システム設定で割り当てられるが、メニューにその項目があるアプリでしか効かない。
- **コピーしたら自動で書式を消す常駐アプリ**: Pure Paste、Rinse、PlainText – Clipboard Cleaner など。
- **クリップボードの履歴アプリの機能**: Raycast・Alfred・Maccy などにある「文字だけで貼る」。
- **コピーの側で消すもの**: CleanBoard(⌘C を 2 回押す)、Plaintext!(⌘C のあと ⌃⌫)。

いくつかのアプリを見てみたが、自分にはピンと来なかった。
多くは「貼るときに消す」か「コピーしたものを全部自動で消す」のどちらかだった。
文字だけのコピーが一発でできて、かつ書式付きのコピーも一発でできる。
そんなものがなかったので作った。

### 作りながら決めたこと

1. **最初は Web 版**: 書式を持てない入力欄に貼って、コピーし直す(Windows のメモ帳と同じ考え方)。`index.html` に残っている。
2. **Mac アプリにした**: 同じことをするウインドウを作った。
3. **どのアプリでも効くショートカット**: 選んで押すだけで文字だけでコピーする。キーは **⌃⌘C** にした。いつもの ⌘C に ⌃ を足すだけで覚えやすく、標準や主なアプリとぶつからない。
   - 候補から外したもの: ⌘X(カット)、⌘B(太字)、⌃C(ターミナルでコマンドを止める)、⌥⌘C(Finder のパスのコピー)。
4. **⌘C と ⌃⌘C の入れ替え**: いつもの ⌘C を文字だけにしたいときのために、メニューのチェックで入れ替えられるようにした。今の割り当ては、メニューの上の札でいつでも見られる。
5. **7 言語に対応**: 英語・日本語・中国語(簡体字)・韓国語・ドイツ語・フランス語・スペイン語。

## Mac アプリ(HotPlainText)

- どのアプリでも、文字を選んで **⌃⌘C** を押すと文字だけでコピーする(アクセシビリティの許可が要る)
- ウインドウに貼り付けると書式が消える。「ペースト」で貼り付け、「コピー」で文字だけをコピー(選んでいればその部分、なければ全文)
- メニューバーから「⌘C と ⌃⌘C を入れ替える」「ログイン時に起動する」「言語」を切り替えられる

### インストール

自分の Mac でビルドして入れる。その Mac で作ったアプリなので、「開発元を確認できません」の警告は出ない。

要るもの: macOS 14 以降、Xcode のコマンドラインツール(入っていなければ `xcode-select --install`)。

```bash
git clone https://github.com/xzelvox/HotPlainText.git
cd HotPlainText/HotPlainText && ./install.sh
```

`install.sh` はビルドして、前の HotPlainText があれば終了させて消し、新しいものを入れて開く。その場の署名のときは前のアクセシビリティの許可も消すので、開いたら案内どおりに付け直す。

ビルドのときに「その場の署名にします」という注意が出るが、そのままでよい。

初めて開くと、⌃⌘C に要るアクセシビリティの許可の付け方が出る。案内どおりに付けると、アプリが自動で開き直す。メニューの上の札に緑の点と「アクセシビリティ: 許可あり」が出れば使える。

新しい版にするときは、`git pull` してから、もう一度 `./install.sh` を動かす。

アイコンは `make_icon.swift` で描いている。

表示は英語・日本語・中国語(簡体字)・韓国語・ドイツ語・フランス語・スペイン語に対応し、Mac の言語設定に合わせて切り替わる(対応していない言語なら英語)。メニューの「言語」から選ぶこともできる。
文言は `*.lproj/Localizable.strings` にある(英語は基本の言語で、キーがそのまま表示になる)。全言語の訳の一覧は `HotPlainText/TRANSLATIONS.md`。

## Web 版

`index.html` をブラウザで開き、貼り付けて「すべてコピー」を押す。
